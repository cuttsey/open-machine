# Contributing to the AI Agent Incident Tracker

Thank you for helping to maintain this record. The goal is accuracy, transparency, and completeness.

## Reporting a New Incident

If you know of an AI agent incident not yet listed in the inventory, you can contribute in two ways:

### Option 1: Open an Issue

Create a new issue with the following information:

- **Incident title** — a short, descriptive name
- **Date** — when the incident occurred or was reported
- **Category** — which of the six categories it falls under (see README)
- **What happened** — 2–3 sentences describing the incident
- **Impact** — who was affected and how
- **Source** — a link to a credible report (news article, security advisory, blog post)

### Option 2: Submit a Pull Request

Edit `incident_inventory.md` directly and submit a PR. Please follow the existing format for entries:

```markdown
**Incident Title (Date)**
- **What happened:** 2–3 sentence description.
- **Impact:** Brief impact statement.
- **Source:** [Source Name](URL)
```

## Quality Standards

- **Sources must be credible.** Acceptable sources include established news outlets, security research firms, official advisories, and first-person accounts from verified individuals. Forum posts and social media alone are not sufficient unless corroborated.
- **Incidents must be documented, not speculative.** We track what has happened, not what might happen.
- **Neutral tone.** Describe what occurred factually. Avoid editorialising or assigning blame beyond what sources support.
- **No duplicate entries.** Check the existing inventory before submitting. If an existing entry is incomplete, update it rather than creating a new one.

## Correcting an Existing Entry

If you believe an entry contains an error, please open an issue or PR with:

- The entry you believe is incorrect
- The specific claim that needs correction
- A source supporting the correction

## Automated Updates

The inventory is updated daily by an automated workflow. Human contributions are merged alongside automated updates. If a conflict arises, human-verified information takes precedence over automated scans.

## Code of Conduct

This project exists to document harm caused by AI agents. Contributors are expected to engage constructively and respectfully. We do not tolerate harassment, personal attacks, or deliberately misleading contributions.
